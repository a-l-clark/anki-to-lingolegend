1. Upload your Anki export

In Anki: File → Export…, choose “Anki Deck Package (.apkg)”. Include scheduling information or not — it doesn't matter, only the card content is used.

Drop your .apkg file here, or click to choose one Nothing leaves your browser — parsing happens entirely on your device.

Uncheck any note types or decks you don't want exported.

3. Map Anki fields to Lingo Legend columns

Each note type gets its own mapping, since field names can differ. We've guessed some matches — check them over. Fields marked * are required by the template. Topic Description and Topic Type aren't mapped here — you'll set those once per topic in the next step.

Text cleanup

Pronunciation Override always has any 〜 characters stripped out, regardless of the toggles below.

Clean Anki formatting
Strips HTML tags, [sound:…] references, LaTeX/cloze markup, and decodes HTML entities before export.
Extract furigana readings
If a field uses the Anki Japanese-support format 漢字[かんじ], split the bracketed reading out into Pronunciation Override (only for columns left unmapped) and leave plain text behind. If a row has no furigana at all, Native Text is used as the Pronunciation Override instead.
Make tags readable
Applies to any column sourced from Anki tags. Replaces _, -, and . with spaces, splits camelCase/PascalCase into separate words, and turns hierarchical tags like topic::verb_forms into topic / verb forms.

4. Topic details

The template only fills in Description & Type on the first row of each topic. Add them here once per topic — optional. Drag the ⠿ handle to reorder topics; this also sets the order they appear in the exported CSV.
